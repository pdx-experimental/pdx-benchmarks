# Formal A12 release scope

Phase 2 is a separate historical exploratory study, not part of the A12 denominator. Its exclusion was a release-scope decision, not a finding of invalidity. See [Phase 2 audit status](PHASE2_STATUS.md) for verified scoring consistency, the absence of Engine dispatch in the retained execution path, and outstanding disclosure work.

The [sanitized historical archive](../slm-task-governance/archive/legacy-phase0-3/) now separately includes available Phase 0–3 exploratory data, source, tests, notebooks and wrapped report transcripts. No separately identified Phase 1 dataset was found in the retained export. These artifacts are excluded from the A12 denominator, not from research visibility. Historical reports are not current endorsed conclusions. Binary reports, credentials, account identifiers and caches remain excluded.

Included: 28 formal job exports (1,444 rows), sanitized ledgers, unchanged Engine evidence and SQLite databases, original manifests as provenance references, derived public manifests, three current Markdown reports, scoring and CPU verification code.

Excluded from the A12 analysis: historical exploratory data and claims, old runners and notebooks. Available sanitized historical materials are disclosed in the separate archive described above. Excluded from the public file set: credentials, cloud logs, private source snapshots outside the selectively disclosed protocol evidence and historical archive, local audit scratch, PDF editions without completed visual review. Excluded local material is retained outside this Git repository. The public repository was recreated; historical private Git objects are not included.

Original manifests describe original bundles; their ledger hashes do not describe sanitized ledgers. Public manifests bind exported files. Self-digests check integrity; they are not identity signatures or independent timestamps. Offline verification does not establish remote job version identity or exhaustiveness of retries.

Phase 3 uses hierarchical prompt conditions, not an orthogonal factorial design. The six-comparison Holm family was selected post hoc; the full eighteen-comparison family is also reported. Outcomes concern combined prompt and execution interventions, not an isolated causal effect of the Engine.

Security review covers the current release file set. Pattern scanning cannot guarantee absence of all possible secrets. Previously published history requires separate treatment if a credential is discovered.

Selected original protocol snapshots and TSA receipts are now included for retrospective audit. See [the evidence limitations](../slm-task-governance/evidence/frozen-protocol/README.md); v5 timestamp verification is explicitly failed.
